# Rules sources

| Source | Use |
| --- | --- |
| [Athas.org Dark Sun 3 v8](https://www.athas.org/products/ds3) | Baseline 3.5 races (Chapter 1), classes (Chapter 2), heroic characteristics (Chapter 3), defiling, Hidden Talent feats |
| [d20 SRD — Classes](https://www.d20srd.org/indexes/classes.htm) | PHB class mechanics inlined where DS3 defers (barbarian, cleric, druid, fighter, ranger, rogue, wizard) |
| [d20 SRD — Psionics](https://www.d20srd.org/srd/psionic/) | EPH psion, psychic warrior, wilder mechanics where DS3 defers |
| [Birthright blood ability structure](https://birthright.net/wiki/index.php/Blood_abilities) | d100 table layout, LS/ability slot model (OGL) |
| [Expanded Psionics Handbook](https://www.d20srd.org/srd/psionic/) | Psionics, Hidden Talent, wild talent powers |
| [Matthew Hope — Wild Talents PDF](https://www.enworld.org/ericnoah/conversions/wild_talents.pdf) | 2e-style wild talent conversion |
| Table ruling | Primordial legacies, legacy power mechanics, Shattering premise |

Legacy power **names and effects** are table-original Athasian content, not BRCS ability ports.
