# Wild talent tables (default)

**Table default** for wild talents. For player-chosen powers, see [Hidden Talent](hidden-talent.md).

Requires **Expanded Psionics Handbook** for full power text.

## Step 1: Wild talent chance

Every character makes a **wild talent check** at 1st level (before choosing Hidden Talent).

| Modifier | Chance |
| --- | --- |
| Base | 1% |
| Int, Wis, or Con 16 | +1% each |
| Int, Wis, or Con 17 | +2% each |
| Int, Wis, or Con 18+ | +3% each |
| Character level 5–8 | +1% |
| Character level 9+ | +2% |
| Nonhuman | ×½ (round up; apply once) |
| Wizard, priest, or psionic class | ×½ (apply once total with nonhuman) |

Roll d%. If result **≤** modified chance → wild talent. If **> chance and < 97** → no talent.

**Optional (2e):** Roll 97+ → psychic burn/disaster (DM; many tables drop this).

**Optional:** −2 on d% if character received psychic surgery (2e; no 3.5 equivalent unless house-ruled).

## Step 2: Discipline

If the character is a wild talent, roll d100:

| Roll | Discipline |
| --- | --- |
| 01–16 | Clairsentience |
| 17–32 | Metacreativity |
| 33–49 | Psychokinesis |
| 50–66 | Psychometabolism |
| 67–82 | Psychoportation |
| 83–96 | Telepathy |
| 97–98 | Roll twice on this table (ignore 97–00) |
| 99 | Choose one 1st-level power from any discipline |
| 00 | Choose one talent + one 1st-level power |

**Default result:** One **psionic talent** (0-level) from the discipline table below unless 99/00 says otherwise.

## Step 3: Power

Roll d100 on the **talent** table for the discipline, or on the **1st-level** table if step 2 or the DM assigns a higher power. Cap wild talents at **1st level** unless the DM expands the table.

## Manifesting (wild talent)

| Rule | Value |
| --- | --- |
| Power points | 1 per character level (no high-stat bonus) |
| Manifester level | Character level |
| Key ability | Charisma 11+ required to manifest |
| Saves / max power level | Charisma-based |
| Psionic focus | Yes |
| Metapsionic feats | If prerequisites met |

**Optional (Matthew Hope):** Choose one **combat mode** (attack or defense from EPH psionic combat). Low-level wild talents may lack PP to use it.

Psionic class levels use class PP and ML instead of these rules.

### General psion/wilder list (any discipline tag)

Many 1st-level [general powers](https://www.d20srd.org/srd/psionic/powerList.htm) belong to a discipline — use EPH as authority when a power appears on both general and discipline lists.

Common wild talent picks on Athas: **Inertial Armor**, **Force Screen**, **Mindlink**, **Expansion** (psychometabolism via psychic warrior list — DM approval), **Precognition, Defensive**.

## Feats (optional)

Wild talents may qualify for psionic feats per Matthew Hope (if requirements met): Body Fuel, Delay Power, Disarm Mind, Enlarge Power, Extend Power, Greater Power Penetration, Heighten Power, Hide Power, Inner Strength, Maximize Power, Mental Adversary, Mind Trap, Persistent Power, Power Penetration, Psychic Bastion, Quicken Power, Trigger Power (some waive Talented prerequisite).
