# Hidden Talent (alternate)

**Alternate** to [random wild talents](wild-talent-tables.md). Athas.org DS3 points here for high-psionics Athas when not using 2e-style rolls.

## Hidden Talent [General]

**Prerequisite:** 1st level only.

**Benefit:**

- You are a psionic character.
- Gain **2 power points** (stack with class PP if you later take a psionic class).
- Choose **one 1st-level power** from any psionic class list. It becomes a power known.
- Qualify for psionic, metapsionic, and psionic item creation feats.

**Manifesting without psionic class levels:**

- Manifester level **1**
- Requires **Charisma 11+**
- Use Charisma for save DCs and maximum power level

If you have psionic class levels, manifest this power at your highest class manifester level (Hidden Talent ML does not stack with class levels).

## When to use

- Player or DM wants **predictable** wild powers
- Feat economy allows spending 1st-level feat on psionics
- Less randomness than [wild talent tables](wild-talent-tables.md)

## Table variants

| Variant | Rule |
| --- | --- |
| DS3 default | Optional; not automatic |
| Free Hidden Talent | Every PC gets feat at 1st (no cost) — mimics ubiquitous 2e psionics with choice |
| Required | Non-psions must take Hidden Talent or [Wild Talent](https://www.d20srd.org/srd/psionic/feats.htm#wildTalent) (2 PP, no power) at 1st |
| Anti-psionic | Instead of Hidden Talent, allow Hostile Mind or Psionic Hole (EPH) — never psionic feats/classes later |

## Improved Hidden Talent (DS3)

**Prerequisites:** Cha 12, Hidden Talent, character level 3rd.

**Benefit:** Manifest Hidden Talent power at ML = ½ HD (min 1). Charisma grants bonus PP by effective ML.

**Special:** Cannot take or use if you have manifester class levels.

## Greater Hidden Talent (DS3)

**Prerequisites:** Cha 13, Improved Hidden Talent, character level 5th.

**Benefit:** +3 PP; learn one additional 1st- or 2nd-level power. Charisma sets saves.

**Special:** No manifester class levels. May take multiple times for additional powers.

## Wild Talent feat (EPH)

Weaker option: **Wild Talent** grants 2 PP and psionic character status but **no power to manifest**. Use for "psionically sensitive" NPCs who use psionic items/feats only.
