# Psionics (the Way)

On Athas, psionics — **the Way** — is common. Full psions train at places like [Nexus](../../world/landmarks/nexus.md). Most people never develop more than a **wild talent**: one spontaneous power without class levels.

This table documents **two models**. Use one consistently unless the DM says otherwise.

## Default: random wild talent (2e-style)

[Wild talent tables](wild-talent-tables.md) — chance check at 1st level, discipline roll, random power from Expanded Psionics Handbook (EPH). Adapted from 2e *Complete Psionics Handbook* / *Will and the Way* and Matthew Hope's Dark Sun 3 conversion.

**Best for:** Ubiquitous psionics, uneven powers, strong Dark Sun flavor.

## Alternate: Hidden Talent (3.5)

[Hidden Talent](hidden-talent.md) — player chooses one 1st-level EPH power at 1st level via feat. Athas.org DS3 default for structured 3.5 games.

**Best for:** Predictable PCs, feat-economy games, lower randomness.

## Relation to godshards

[Godshards](../godshards.md) (divine blood abilities) and the Way are **separate** by default. A character may be both a scion and a wild talent if the DM allows.

## Full psionic classes

Psion, wilder, psychic warrior, etc. use DS3 + EPH as written. Wild talent rules apply to **non-psionic-class** characters unless they replace this with Hidden Talent.
