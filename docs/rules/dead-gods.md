# Dead gods (superseded)

Scion powers now use **[primordial legacies](legacies.md)** (Sun, Storm, Sea, Stone, Mind, Defiler, Dragon) instead of Birthright derivation names.

The [Shattering](../campaign/premise.md) at Godshold still killed the Green Age pantheon. What leaked into mortals fractured into elemental, psionic, and defiling **legacies** — not Cerilian-style bloodlines.

Use [legacy power tables](blood-abilities/legacy-tables.md) for all new characters.
