# Excluded Classes

DS3 Chapter 2 omits several PHB and EPH classes. The **Behind the Veil** sidebar explains why. These classes are **not** part of this campaign's Athas.org baseline unless the DM adds them.

| Class | Source | Why excluded | DM note |
| --- | --- | --- | --- |
| Monk | PHB | Few monasteries exist; martial-artist monk does not fit Athas tone or numbers | Could work in low-magic games but unbalanced vs. equipment dependence |
| Paladin | PHB | No gods to reward selfless acts; no chivalric tradition; evil is the norm | — |
| Sorcerer | PHB | Overlaps psion spontaneous manifesting; spellcasting without a spellbook clashes with setting flavor | — |
| Soulknife | EPH | No precedent in prior Dark Sun material | Prestige class in Prestige Class Appendix I |
| Trader | 2e Dark Sun | Benefits folded into 3e skills; replicate with rogue, bard, or expert NPC class | Rogue special ability **Dune Trader** covers much of this |

Some DMs run Dark Sun as low-magic, low-treasure. In such games, monk and soulknife (self-sufficient weapons/armor) may become unbalanced.

Athas.org releases do not include these as core classes.
