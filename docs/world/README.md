# World — Athas atlas gazetteer

Campaign geography for this table: regions, settlements, landmarks, and travel notes tied to the interactive map at [`/map`](/map).

## Era and scale

- **Era:** FY 10 (post-Kalak, Athas.org 3.5 baseline).
- **Map scale:** 2e Tablelands miles (Athas.org distance calculator). Not 4e ×3.

Pre-Kalak or 4e-only facts belong in a separate `variants` note on the entity page, not in the main stats.

## Subfolders

| Path | Contents |
| --- | --- |
| [`regions/`](regions/) | WTM/SRM/LRM grid cells and named lands |
| [`settlements/`](settlements/) | Cities, villages, forts, oases |
| [`landmarks/`](landmarks/) | Ruins, shrines, terrain features |
| [`travel/trade-routes.md`](travel/trade-routes.md) | Trade routes and distance rules |

## Map link

Each page with `atlas_id` opens from the atlas side panel. Deep link: `/map?place=<atlas_id>`.
